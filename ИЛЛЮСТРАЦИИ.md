# Иллюстрации для сайта
*Последняя правка: 27.10.2026*

> **Для чего этот документ.** Технический список мест под иллюстрации на сайте: имена файлов, форматы, как картинка обрезается и как её поставить. Пока картинки нет, на её месте видна заглушка с именем («иллюстрация · mk1 · 3:2»).
> **Идеи, настроение и промпты для генерации** — в «09_Оформление/Сайт/Иллюстрации для сайта — идеи и промпты.md».

## Как поставить картинку
1. Сгенерировать в ChatGPT по промпту из документа с промптами.
2. Сохранить в папку `img/ill/` под именем из таблицы: `hero.png`, `mk1.png` и т. д. Подходят `.webp`, `.jpg` и `.png`, код править не нужно: сайт найдёт файл сам.
3. **Сжать.** PNG из ChatGPT весит 2–3 МБ, тринадцать таких картинок тяжело грузить с телефона. Лучше WebP или JPG до 300 КБ, 1200–1500 px по длинной стороне (например, через squoosh.app). Можно просто положить PNG и попросить Claude сжать.
4. Выложить: `git add -A`, `git commit -m "…"`, `git push` (см. README).

| `day` | «Как устроен день», над расписанием | горизонтальный 3:2 | телефон 16:9, компьютер 21:9 — главное держать в средней полосе |

| `quiz` | «Три вопроса — и подскажем», под заголовком | горизонтальный 3:2 | без обрезки |
| `faq` | «Перед тем как прийти», под заголовком | квадрат | без обрезки |
| `place` | «Как добраться», под кнопками | горизонтальный 3:2 | без обрезки |
| `dawn` | Финал — фон за связкой шариков | горизонтальный 3:2 | края растворяются в градиенте раздела, центр закрыт шариками |
