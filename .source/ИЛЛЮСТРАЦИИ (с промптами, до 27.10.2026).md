# Иллюстрации для сайта
*Последняя правка: 27.10.2026*

> **Для чего этот документ.** Список мест под иллюстрации на сайте фестиваля, размеры и готовые промпты для ChatGPT. Пока картинки нет, на её месте видна заглушка с именем («иллюстрация · mk1 · 3:2»).

## Как поставить картинку
1. Сгенерировать в ChatGPT по промпту ниже.
2. Сохранить в папку `img/ill/` под именем из таблицы: `hero.png`, `mk1.png` и т. д. Подходят `.webp`, `.jpg` и `.png`, код править не нужно: сайт найдёт файл сам.
3. **Сжать.** PNG из ChatGPT весит 2–3 МБ, двенадцать таких картинок тяжело грузить с телефона. Лучше WebP или JPG до 300 КБ, 1200–1500 px по длинной стороне (например, через squoosh.app). Можно просто положить PNG и попросить Claude сжать.
4. Выложить: `git add -A`, `git commit -m "…"`, `git push` (см. README).

## Чтобы картинки были одной серией
Все картинки лучше делать в одном чате ChatGPT. Сначала отправить «Общий стиль», затем промпты по одному. Когда первая картинка удалась, добавлять к следующим: «в том же стиле, что и первая».

**Общий стиль** (отправить первым сообщением):

```
Я делаю серию иллюстраций для сайта психологического фестиваля «От Страха к Любви». Все картинки — в одном стиле: нежная книжная иллюстрация акварелью с мягкой гуашью, тёплый свет рассвета, много воздуха, простые крупные формы без мелких деталей. Палитра: сиреневый (#b79cc8), пыльная роза (#e27d7a), персиковый (#f8c9a8), абрикосовый (#f2a35e), кремовый фон (#fffaf5); холодные сиреневые тона означают страх, тёплые абрикосовые — любовь. Люди — обобщённые мягкие фигуры без прорисованных лиц. Настроение спокойное, бережное, светлое, без мрачности. Никакого текста, букв и цифр на картинках. Сейчас ничего не рисуй — жди описаний.
```

## Места под картинки

| Имя файла | Где на сайте | Формат в ChatGPT | Как обрезается на сайте |
|---|---|---|---|
| `hero` | Первый экран, в арке рядом с названием (на телефоне — над названием) | вертикальный 2:3 | арка 4:5 — верх и низ немного срежутся |
| `day` | «Как устроен день», над расписанием | горизонтальный 3:2 | телефон 16:9, компьютер 21:9 — главное держать в средней полосе |
| `mk1` … `mk6` | Обложки карточек мастер-классов | горизонтальный 3:2 | без обрезки |
| `quiz` | «Три вопроса — и подскажем», под заголовком | горизонтальный 3:2 | без обрезки |
| `faq` | «Перед тем как прийти», под заголовком | квадрат | без обрезки |
| `place` | «Как добраться», под кнопками | горизонтальный 3:2 | без обрезки |
| `dawn` | Финал, круг над цитатой | квадрат | круг — углы срежутся |

## Промпты

### hero — главный образ
```
Вертикальная иллюстрация 2:3. Мост-арка над тихой водой на рассвете. Левый берег — в прохладной сиреневой дымке, правый залит тёплым абрикосовым светом встающего солнца. Посередине моста маленькая фигура человека идёт к свету. Главное — в центре кадра, по краям оставить свободное небо и воду: картинку обрежут аркой.
```

### day — как устроен день
```
Горизонтальная иллюстрация 3:2. Светлое уютное пространство психологического центра: три открытые двери в три зала, из окон льётся мягкий утренний свет, на столике чайник и чашки. Небольшие группы людей неспешно переходят из зала в зал. Всё важное — в средней горизонтальной полосе, верх и низ будут обрезаны.
```

### mk1 — «Как Волк научился любить»
```
Горизонтальная иллюстрация 3:2. Волк и маленький телёнок сидят рядом на холме под тёплым рассветным небом. Волк смотрит на телёнка бережно и нежно, телёнок доверчиво прижался к нему. Добрая сказочная книжная иллюстрация. Персонажи — собственного дизайна, не копировать героев мультфильма «Волк и телёнок».
```

### mk2 — «Источник»
```
Горизонтальная иллюстрация 3:2. Из земли бьёт родник, от него по листу бумаги расходятся цветные линии-дорожки, от холодного сиреневого к тёплому оранжевому. В воздухе парят лёгкие полупрозрачные шёлковые платки. Сбоку рука с пастелью дорисовывает свой путь. Ощущение лёгкости, игры и удивления.
```

### mk3 — «Как не бояться любить и жить счастливо?»
```
Горизонтальная иллюстрация 3:2. Два больших дерева, чьи кроны мягко переплетаются, а под ними молодое деревце. Корни всех трёх видны в разрезе земли и сплетаются между собой. Тёплый свет пробивается сквозь листву. Тема: семья, в которой мы выросли, уважение и баланс.
```

### mk4 — «Улыбка»
```
Горизонтальная иллюстрация 3:2. Маленький енот сидит у пруда, смотрит на своё отражение в воде и улыбается. Вокруг камыши, кувшинки, светлячки, вечерний тёплый свет. Игривое, весёлое настроение. Енот — собственного дизайна, не копировать героя мультфильма «Крошка Енот».
```

### mk5 — «Внутренняя вертикаль»
```
Горизонтальная иллюстрация 3:2. Человек стоит прямо и спокойно, босиком на траве, глаза закрыты. От стоп в землю уходят мягкие светящиеся корни, вдоль спины вверх к небу поднимается тонкий тёплый луч света. Простор, утренний воздух, ощущение опоры и силы.
```

### mk6 — «Кто стоит за моим страхом?»
```
Горизонтальная иллюстрация 3:2. Человек виден со спины, стоит на рассвете. Позади него полукругом стоят полупрозрачные светлые фигуры предков, положив ладони на плечи друг другу, тепло передаётся по цепочке вперёд, к человеку. Ощущение поддержки и опоры за спиной, светло, совсем не мрачно.
```

### quiz — с чего начать
```
Горизонтальная иллюстрация 3:2. Развилка тропинок в цветущем луговом поле на рассвете. Деревянный указатель без надписей, лёгкий туман. Одна тропа уходит к холму, над которым встаёт солнце, другая — к роще. Спокойное приглашение выбрать свой путь.
```

### faq — что взять с собой
```
Квадратная иллюстрация. Уютный натюрморт: свёрнутый мягкий плед, пара тёплых шерстяных носков, чашка чая с лёгким паром, бутылка воды и блокнот. Светлый кремовый фон, мягкий утренний свет сбоку.
```

### place — как добраться
```
Горизонтальная иллюстрация 3:2. Старый петербургский дом на Лиговском проспекте ранним утром: светлый фасад, тёплые окна, вход во двор через арку. Мягкий рассветный свет, редкие прохожие-силуэты. Без вывесок и надписей.
```
Сюда лучше подойдёт настоящее фото входа в центр «МирРа», если оно есть.

### dawn — финал
```
Квадратная иллюстрация. Солнце поднимается над спокойной водой, вдали силуэт моста-арки. Небо переходит от сиреневого вверху к тёплому абрикосовому у горизонта, солнце ровно в центре. Картинку обрежут кругом, поэтому главное — в центре.
```
