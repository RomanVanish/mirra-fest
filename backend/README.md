# Заявки с сайта → рабочая группа в Telegram
*Последняя правка: 28.10.2026*

Как это работает:
1. Гость отправляет форму на сайте.
2. Заявка уходит в облачную функцию Яндекс Облака.
3. Функция пишет сообщение в закрытую группу в Telegram.

Копия каждой заявки остаётся в журнале функции на случай, если мессенджер не ответит.

```
сайт (GitHub Pages) → функция Yandex Cloud (index.py) → бот Telegram → группа «Заявки»
                                                       ↘ бот Max (позже, когда будет профиль организации)
```

Функция умеет писать и в Telegram, и в Max. Канал включается, когда в настройках функции задан его токен. Если включены оба, заявка уходит в оба. Достаточно, чтобы дошла хотя бы в один.

## Файлы

| Файл | Что это |
|---|---|
| `index.py` | код функции (Python 3.12, без сторонних библиотек) |
| `russian_trusted_ca.pem` | сертификаты Минцифры, нужны только для Max: его API подписан ими |
| `telegram-proxy-worker.js` | посредник для Telegram на Cloudflare Workers: из Яндекс Облака Telegram напрямую недоступен |
| `fest-zayavki.zip` | два файла выше, упакованные для загрузки в Яндекс Облако |

> **Токен бота никуда не вписывать и никому не пересылать** — ни в код, ни в чат с нейросетью. Он задаётся только в настройках функции в Яндекс Облаке. Если токен всё же попал не туда: @BotFather → `/revoke` → выбрать бота. Старый токен перестанет работать, придёт новый.

## Подключение — шаг за шагом

### 1. Бот в Telegram

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) (официальный, с синей галочкой) и отправьте `/newbot`.
2. Задайте **имя**, например «Заявки МирРа — фестиваль».
3. Задайте **ник**, он должен заканчиваться на `bot`, например `mirra_fest_zayavki_bot`.
4. BotFather пришлёт **токен** вида `1234567890:AAH…`. Это пароль бота: сохраните его, он понадобится на шаге 3.

### 2. Группа для заявок

1. Создайте группу, например «Заявки — От Страха к Любви», и добавьте в неё всех, кто записывает гостей.
2. Добавьте в группу бота по нику. Права администратора ему не нужны: бот только пишет.
3. Напишите в группе `/start@ник_бота`, например `/start@mirra_fest_zayavki_bot`.

### 3. Функция в Яндекс Облаке

1. Откройте [console.yandex.cloud](https://console.yandex.cloud) и войдите своим Яндекс ID.
   - Если облака ещё нет, создайте его вместе с платёжным аккаунтом.
   - Карту привязать придётся. Но у функций есть бесплатный объём — миллион вызовов в месяц, а заявок будет на порядки меньше, так что платить не придётся.
2. **Cloud Functions** → **Создать функцию**, имя `fest-zayavki`.
3. **Редактор**: среда выполнения **Python 3.12**, галочку «Добавить файлы с примерами кода» снять.
4. **Способ** → **ZIP-архив** → загрузить `backend/fest-zayavki.zip`.
5. **Точка входа** `index.handler`, **таймаут** 15 секунд, **память** 128 МБ.
6. **Переменные окружения**: `TG_TOKEN` — токен из шага 1. `TG_CHAT_ID` пока **не добавлять**.
7. **Сохранить изменения**: появится первая версия.
8. Вкладка **Обзор** → включить **Публичная функция** → скопировать **Ссылку для вызова** вида `https://functions.yandexcloud.net/d4e…`.

### 4. Узнать id группы

1. В функции откройте вкладку **Тестирование**, выберите шаблон «Без шаблона» и вставьте во «Входные данные»:
   ```json
   {"httpMethod": "POST", "body": "{\"setup\": true}"}
   ```
2. **Запустить тест**. В ответе будут ник бота и список групп. Скопируйте число из `TG_CHAT_ID` — оно отрицательное, например `-4012345678` или `-1001234567890`.
   - **Список пуст?** Удалите бота из группы и добавьте снова, напишите `/start@ник_бота`, запустите тест ещё раз. Telegram хранит такие события сутки.
   - **Вместо списка «Telegram недоступен»?** Значит, Яндекс Облако не достучалось до Telegram: нужен посредник, см. раздел «Если Telegram недоступен».
3. **Редактор** → **Переменные окружения** → добавить `TG_CHAT_ID` с этим числом → **Сохранить изменения**.

Когда id группы задан, режим настройки выключается сам: посторонние не увидят список групп.

### 5. Включить форму на сайте

1. Ссылку для вызова из шага 3 впишите в `index.html`, в строку `var FORM_ENDPOINT = "";`. Ссылка не секретная — можно прислать её в чат, Claude впишет.
2. Отправьте с сайта тестовую заявку. В группе должно появиться «🌿 Новая заявка на фестиваль».

## Если что-то не так

- **Заявка не пришла, а сайт пишет «Не получилось отправить».**
  1. Откройте функцию → **Логи** и найдите строку `send_failed`. В ней ответ мессенджера:
     - `401 Unauthorized` — неверный токен;
     - `400 chat not found` или `403 bot was kicked` — бота нет в группе или указан не тот `TG_CHAT_ID`.
  2. Сама заявка лежит в той же ленте логов, в строке `request`.
- **Группу сделали супергруппой** (Telegram делает это сам, например при включении истории для новых участников). У группы меняется id. Функция это заметит и отправит заявку на новый id. В логах появится `tg_chat_migrated` с новым числом: впишите его в `TG_CHAT_ID`.
- **Сайт переехал на другой адрес.** Добавьте переменную `ALLOWED_ORIGINS` — адреса через запятую, например `https://fest.mirra-spb.ru,https://новый-адрес.ru`. Заявки с других сайтов функция не принимает.
- **Спам.** В форме есть скрытое поле: люди его не видят, а боты заполняют. Ещё функция отсекает заявки, отправленные быстрее чем за 3 секунды. В обоих случаях она отвечает «принято», но ничего не пересылает, а в логах пишет `spam`.
- **Проверка заявки.** Заявку без имени, без телефона из 10–15 цифр или без согласия на обработку данных функция не принимает.

### Если Telegram недоступен из Яндекс Облака — посредник на Cloudflare

Проверено 28.10.2026: из Яндекс Облака `api.telegram.org` не открывается, тест отвечает `Telegram недоступен: … timed out`. Тильда на mirra-spb.ru отправляет заявки со своих зарубежных серверов, поэтому у неё всё работает. Мы делаем так же: функция в Яндекс Облаке принимает и записывает заявку, а в Telegram передаёт её через бесплатный посредник на Cloudflare Workers.

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com/sign-up). Нужна только почта, карта не нужна.
2. **Workers & Pages** → **Create** → **Create Worker** (шаблон «Hello World»). Имя: `mirra-tg`. Нажмите **Deploy**.
3. Нажмите **Edit code**, удалите всё содержимое и вставьте текст файла `backend/telegram-proxy-worker.js`. Нажмите **Deploy**.
4. Скопируйте адрес посредника вида `https://mirra-tg.<ваше-имя>.workers.dev`.
   - Если открыть его в браузере, будет `not found`. Это нормально: посредник отвечает только запросам нашего бота.
5. В Яндекс Облаке: функция → **Редактор** → **Переменные окружения** → добавьте `TG_API` с этим адресом, без `/` на конце → **Сохранить изменения**.
6. Дождитесь сборки версии и снова запустите тест `{"setup": true}` (шаг 4).

Посредник пропускает только запросы бота с номером `9019391857` (номер записан в коде посредника). Токен на Cloudflare не хранится: его каждый раз присылает функция. Если бот поменяется, замените номер в `BOT_ID` в коде посредника.

Если не сработает и посредник, есть ещё варианты:
- **Max** — когда появится проверенный профиль организации (раздел ниже);
- **почта центра** — пишите, допишу.

## Max — когда будет профиль организации

> Бота в Max может создать только **проверенный профиль организации, ИП или самозанятого** на [business.max.ru](https://business.max.ru). После создания бот проходит модерацию.

1. На business.max.ru: **Чат-боты** → **Создать бота**. Ник — латиницей, от 11 до 60 символов, на конце `bot`. После модерации токен лежит в **⋮** → **Настройки**.
2. Создайте группу в Max, добавьте бота и **сделайте его администратором**, иначе он не увидит группу. Напишите в группе любое сообщение.
3. В функции добавьте переменную `MAX_TOKEN`, сохраните и запустите тот же тест `{"setup": true}`. Число из `MAX_CHAT_ID` впишите в переменную `MAX_CHAT_ID`.

## После правки index.py

Пересоберите архив и снова загрузите его в функцию (шаг 3.4). Команду запускать из папки `backend/`:

```bash
python -c "import zipfile as z; f=z.ZipFile('fest-zayavki.zip','w',z.ZIP_DEFLATED); [f.write(n) for n in ('index.py','russian_trusted_ca.pem')]; f.close()"
```
