# Заявки с сайта → чат ВКонтакте, запасной путь — почта
*Последняя правка: 29.10.2026*

Как это работает:
1. Гость отправляет форму на сайте.
2. Заявка уходит в облачную функцию Яндекс Облака.
3. Функция отправляет **сообщение в чат сотрудников ВКонтакте**.
4. Если ВКонтакте не принял сообщение, функция отправляет **письмо на почту центра**.

В обычном случае заявка приходит только в ВК, письмо уходит лишь при сбое.
5. Функция дописывает заявку строкой в **таблицу на Яндекс Диске центра** — список гостей и база для рассылки (колонка «Рассказывать о мероприятиях»).

Копия каждой заявки остаётся и в журнале функции.

```
сайт (GitHub Pages) → функция Yandex Cloud (index.py) → сообщение сообщества ВК в чат
                                                         ↘ если не дошло: письмо через Яндекс Почту
                                                         ↘ всегда: строка в таблице на Яндекс Диске
```

**Почему не Telegram.** Проверено 28.10.2026: из Яндекс Облака не открывается ни `api.telegram.org`, ни посредник на Cloudflare — оба отвечают таймаутом. Тильда на mirra-spb.ru шлёт заявки со своих зарубежных серверов, поэтому у неё Telegram работает. Код для Telegram и Max в функции остался. Канал включается, как только заданы его переменные — например, если появится свой зарубежный сервер-посредник или подтверждённый профиль организации в Max.

## Файлы

| Файл | Что это |
|---|---|
| `index.py` | код функции (Python 3.12, без сторонних библиотек) |
| `russian_trusted_ca.pem` | сертификаты Минцифры — нужны только для Max, его API подписан ими |
| `telegram-proxy-worker.js` | посредник для Telegram на Cloudflare Workers. Сейчас не помогает: Cloudflare из Яндекс Облака тоже недоступен |
| `fest-zayavki.zip` | `index.py` и сертификаты, упакованные для загрузки в Яндекс Облако |

> **Пароли и ключи никуда не вписывать и никому не пересылать** — ни в код, ни в чат с нейросетью. Они задаются только в переменных функции в Яндекс Облаке.

## Подключение — шаг за шагом

### 1. Почта: ящик-отправитель и пароль приложения

Письма уходят с ящика на Яндекс Почте. Лучше завести отдельный ящик, например `fest.zayavki@yandex.ru`: пароль от него будет храниться в Облаке, и рисковать основной почтой центра незачем.

1. Войдите в этот ящик на [mail.yandex.ru](https://mail.yandex.ru).
2. ⚙ → **Все настройки** → **Почтовые программы**. Отметьте:
   - «С сервера imap.yandex.ru по протоколу IMAP»;
   - «Пароли приложений и OAuth-токены».
3. Откройте [id.yandex.ru](https://id.yandex.ru) → **Безопасность** → **Пароли приложений** → **Создать пароль** → тип **Почта**, название «Сайт фестиваля».
4. Скопируйте пароль. Он показывается **один раз**.

### 2. ВКонтакте: сообщество, ключ и беседа

Подойдёт сообщество центра, где вы администратор, или новое — например, «Фестиваль От Страха к Любви».

1. В сообществе: **Управление** → **Сообщения** → **Сообщения сообщества: включены**.
2. Там же, вкладка **Настройки для бота**:
   - **Возможности ботов: включены**;
   - отметьте «**Разрешать добавлять сообщество в беседы**».
3. **Управление** → **Дополнительно / Работа с API** → **Ключи доступа** → **Создать ключ**.
   - Отметьте «**Разрешить приложению доступ к сообщениям сообщества**».
   - Подтвердите кодом из СМС или приложения и скопируйте ключ.
4. Создайте беседу ВКонтакте с теми, кто записывает гостей, например «Заявки — От Страха к Любви».
5. Откройте страницу сообщества → под обложкой **⋯** → **Добавить в беседу** → выберите эту беседу.
6. Напишите в беседе любое сообщение.

### 3. Переменные функции в Яндекс Облаке

Функция → **Редактор**:

1. **Способ** → **ZIP-архив** → загрузите новый `backend/fest-zayavki.zip`.
2. **Таймаут** — 20 секунд.
3. **Переменные окружения**:
   - **удалите** `TG_TOKEN` и `TG_API`: Telegram из Облака всё равно недоступен, а лишняя попытка замедлит проверку;
   - `MAIL_USER` — ящик-отправитель из шага 1, например `fest.zayavki@yandex.ru`;
   - `MAIL_PASSWORD` — пароль приложения из шага 1;
   - `MAIL_TO` — куда слать заявки, можно несколько адресов через запятую. Если не задать, письма придут на тот же ящик;
   - `VK_TOKEN` — ключ сообщества из шага 2;
   - `VK_PEER_ID` — пока **не добавлять**.
4. Нажмите **Сохранить изменения** и дождитесь сборки версии (вкладка **Операции**).

### 4. Проверка и id беседы

1. Вкладка **Тестирование** → шаблон «Без шаблона» → во «Входные данные»:
   ```json
   {"httpMethod": "POST", "body": "{\"setup\": true}"}
   ```
2. **Запустить тест**. В ответе:
   - `"Почта": {"вход в ящик": "выполнен"}` — почта настроена;
   - `"ВКонтакте": {"беседы": [{"VK_PEER_ID": 2000000001, …}]}` — скопируйте число `VK_PEER_ID`, оно начинается на `2000000…`.
3. **Редактор** → переменная `VK_PEER_ID` с этим числом → **Сохранить изменения**.

Когда `VK_PEER_ID` задан, режим настройки выключается сам.

### 5. Таблица заявок на Яндекс Диске

Функция дописывает каждую заявку в файл `__Клиенты/Заявки фестиваля/Заявки на фестиваль Душа.csv` на Диске центра. У тех, у кого Диск синхронизируется, файл лежит в той же папке на компьютере и открывается в Excel двойным щелчком. Папку «Заявки фестиваля» функция создаст сама при первой заявке.

Колонки: дата и время, имя, телефон (`+79001234567`), ник, когда придёт, сколько человек, на какой МК, «Рассказывать о мероприятиях» (да/нет), «Куда пришла заявка» (ВКонтакте, Почта или «не доставлена»).

**Как включить.** Нужен ключ (токен) от Диска центра.

1. Войдите в браузере в аккаунт Яндекса, которому принадлежит Диск центра (centrmirra@yandex.ru).
2. Откройте [oauth.yandex.ru/client/new](https://oauth.yandex.ru/client/new) и выберите «**Для доступа к API или отладки**».
3. Название — «Заявки фестиваля». Доступы: **Яндекс Диск REST API** → «**Чтение всего Диска**» и «**Запись в любом месте на Диске**». Больше ничего не отмечайте. Если адрес обратного вызова (Redirect URI) спросят, укажите `https://oauth.yandex.ru/verification_code`.
4. Создайте приложение и получите токен: кнопкой «Получить отладочный токен», если она есть, или откройте `https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_ClientID` → **Разрешить**. ClientID не секретный, а токен **секретный** — никому не пересылать.
5. Функция → **Редактор** → загрузите новый `fest-zayavki.zip` и добавьте переменные:
   - `DISK_TOKEN` — токен;
   - `DISK_PATH` — `disk:/__Клиенты/Заявки фестиваля/Заявки на фестиваль Душа.csv`.

   Нажмите **Сохранить изменения**.
6. Отправьте тестовую заявку. Через минуту файл появится на Диске.

> Такой токен открывает **весь** Диск центра, поэтому он хранится только в переменных функции. Если когда-нибудь он попадёт не туда, отзовите его на [id.yandex.ru](https://id.yandex.ru) → Безопасность → Устройства и приложения и получите новый.
> Есть вариант надёжнее: доступ только «**к папке приложения на Диске**», а `DISK_PATH` не задавать. Тогда файл ляжет в `Приложения/<название приложения>/Заявки на фестиваль.csv`, и функция не будет видеть ничего другого на Диске.

**Правила для таблицы**
- **Не редактируйте и не пересохраняйте сам файл.** Функция каждый раз скачивает его, дописывает строку и загружает обратно. Правки, сделанные в это время, могут пропасть. Если сохранить файл из Excel в другой кодировке, функция перестанет его трогать и будет писать ошибку в журнал. Для работы сохраните копию (Файл → Сохранить как → `.xlsx`) и делайте пометки в ней.
- Тестовые строки удалять, когда заявок нет: открыть файл в Блокноте, удалить строки, сохранить в UTF-8.
- Если две заявки придут в одну и ту же секунду, одна строка может не записаться. В ВК или на почту обе придут, а сама заявка останется в журнале.
- Токен действует не меньше года. Если строки перестали появляться, а в журнале `table_failed … 401`, получите новый токен по шагу 4 и замените `DISK_TOKEN`.
- Если Диск не ответил, заявка всё равно уйдёт в ВК или на почту, а в журнале будет `table_failed`.

### 6. Включить форму на сайте

1. Вкладка **Обзор** → **Публичная функция** включена → скопируйте **Ссылку для вызова**. Ссылка не секретная — пришлите её Claude.
2. Claude отправит тестовую заявку и впишет ссылку в `FORM_ENDPOINT` в `index.html`.
3. Проверьте, что заявка «🌿 Новая заявка на фестиваль» пришла в чат ВК. На почту она уйдёт, только если ВК не ответит.

## Если что-то не так

- **Ошибки в тесте настройки (шаг 4)** и что они значат:
  - `Почта: SMTPAuthenticationError … Invalid user or password` — неверный ящик или пароль приложения, либо в настройках почты не отмечены «Почтовые программы» (шаг 1.2);
  - `ВКонтакте …: 5 User authorization failed` — неверный ключ сообщества;
  - `ВКонтакте …: 15` или `27` — у ключа нет права на сообщения (шаг 2.3);
  - `ВКонтакте …: 917` или `7` — сообщество не добавлено в беседу.
- **Куда ушла заявка.** Функция → **Логи**. Строка `delivered` — канал, который принял заявку. `send_failed` — канал, который не смог, с текстом ошибки.
- **В таблице нет строки.** В логах ищите `table_saved` (записано) или `table_failed` с текстом ошибки. Если нет ни того, ни другого, не задан `DISK_TOKEN`.
- **Заявка не пришла никуда.** В логах будут две строки `send_failed`, сначала ВКонтакте, потом почта. Сама заявка лежит в той же ленте, в строке `request`.
- **Письма попадают в спам.** Добавьте ящик-отправитель в контакты получателя или создайте правило «не спам».
- **Сайт переехал.** Переменная `ALLOWED_ORIGINS` — адреса сайтов через запятую. С других сайтов заявки не принимаются.
- **Защита от спама.** Скрытое поле в форме, которое заполняют только боты, и отсечка заявок, отправленных быстрее чем за 3 секунды. Такие заявки функция не пересылает, в логах пишет `spam`.
- **Проверка заявки.** Без имени, без телефона из 10–15 цифр или без согласия на обработку данных функция заявку не принимает.

## Другие каналы (код уже в функции)

- **Telegram** — `TG_TOKEN` и `TG_CHAT_ID` (бот от @BotFather, группа, id группы через тот же тест настройки). Из Яндекс Облака сейчас недоступен. Если появится свой зарубежный сервер — поставить на него посредник из `telegram-proxy-worker.js` и указать его адрес в `TG_API`.
- **Max** — `MAX_TOKEN` и `MAX_CHAT_ID`. Нужен **проверенный профиль организации, ИП или самозанятого** на [business.max.ru](https://business.max.ru):
  1. Создать бота (ник 11–60 символов, на конце `bot`) и пройти модерацию. Токен — **⋮** → **Настройки**.
  2. Добавить бота в группу администратором.
  3. id группы — через тест настройки.

## После правки index.py

Пересоберите архив и загрузите его в функцию заново. Команду запускать из папки `backend/`:

```bash
python -c "import zipfile as z; f=z.ZipFile('fest-zayavki.zip','w',z.ZIP_DEFLATED); [f.write(n) for n in ('index.py','russian_trusted_ca.pem')]; f.close()"
```
