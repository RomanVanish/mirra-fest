# Заявки с сайта → группа в Max
*Последняя правка: 28.10.2026*

Гость отправляет форму на сайте. Заявка уходит в облачную функцию Яндекс Облака, функция пишет сообщение в закрытую группу Max. Копия каждой заявки остаётся в журнале функции на случай, если Max не ответит.

```
сайт (GitHub Pages) → функция Yandex Cloud (index.py) → бот Max → группа «Заявки»
```

## Файлы

| Файл | Что это |
|---|---|
| `index.py` | код функции (Python 3.12, без сторонних библиотек) |
| `russian_trusted_ca.pem` | корневой и промежуточный сертификаты Минцифры (скачаны с gu-st.ru). Нужны, потому что API Max (`platform-api2.max.ru`) подписан ими |
| `fest-zayavki.zip` | два файла выше, упакованные для загрузки в Яндекс Облако |

> **Токен бота никуда не вписывать и никому не пересылать: ни в код, ни в чат с нейросетью.** Он задаётся только в настройках функции, в Яндекс Облаке.

## Подключение — шаг за шагом

### 1. Бот в Max

> Создать бота может только **проверенный профиль организации, ИП или самозанятого** на платформе MAX для партнёров. После создания бот проходит модерацию. Профиль заводится на ООО «ИРБИС» (или на того, кто будет владельцем бота).

1. Откройте [business.max.ru](https://business.max.ru) и войдите. Создайте и подтвердите профиль организации: платформа сама подскажет способ.
2. Раздел **Чат-боты** → **Создать бота**:
   - **имя** — например, «Заявки МирРа»;
   - **ник** — латиницей, от 11 до 60 символов, должен заканчиваться на `bot`. Например, `mirra_zayavki_bot`.
3. Дождитесь, пока бот пройдёт модерацию: статус виден рядом с его названием.
4. Токен лежит здесь: **Чат-боты** → **⋮** у бота → **Настройки**. Он понадобится на шаге 3. Это пароль бота, храните его как пароль.

### 2. Группа для заявок

1. В Max создайте группу, например «Заявки — От Страха к Любви», и добавьте в неё всех, кто записывает гостей.
2. Добавьте в группу бота (найти его можно по нику).
3. **Сделайте бота администратором группы.** Иначе он не увидит, что его добавили, и шаг 4 не сработает.
4. Напишите в группе любое сообщение, например «привет».

### 3. Функция в Яндекс Облаке

1. Откройте [console.yandex.cloud](https://console.yandex.cloud) и войдите тем же Яндекс ID.
   - Если облака ещё нет, создайте его вместе с платёжным аккаунтом. Привязать карту придётся, но у функций есть бесплатный объём: миллион вызовов в месяц. Заявок с сайта будет на порядки меньше, поэтому платить не придётся.
2. **Cloud Functions** → **Создать функцию**. Имя: `fest-zayavki`.
3. Откроется **Редактор**. Выберите среду выполнения **Python 3.12** и снимите галочку «Добавить файлы с примерами кода».
4. В поле **Способ** выберите **ZIP-архив** и загрузите `backend/fest-zayavki.zip`.
5. Параметры:
   - **Точка входа:** `index.handler`;
   - **Таймаут:** 15 секунд;
   - **Память:** 128 МБ.
6. **Переменные окружения:**
   - `MAX_TOKEN` — токен бота из шага 1;
   - `MAX_CHAT_ID` — пока **не добавлять**.
7. Нажмите **Сохранить изменения**: появится первая версия функции.
8. Вкладка **Обзор** → включите **Публичная функция**. Скопируйте **Ссылку для вызова** вида `https://functions.yandexcloud.net/d4e…`.

### 4. Узнать id группы

1. В функции откройте вкладку **Тестирование**. Выберите шаблон «Без шаблона» и вставьте во «Входные данные»:
   ```json
   {"httpMethod": "POST", "body": "{\"setup\": true}"}
   ```
2. Нажмите **Запустить тест**. В ответе будет имя бота и список групп. Скопируйте число из поля `MAX_CHAT_ID`, обычно отрицательное, например `-71234567890`.
   - Список пуст? Проверьте, что бот — администратор группы. Напишите в группе ещё одно сообщение и запустите тест снова.
3. Вкладка **Редактор** → **Переменные окружения** → добавьте `MAX_CHAT_ID` с этим числом → **Сохранить изменения**.

Когда `MAX_CHAT_ID` задан, режим настройки выключается сам: никто посторонний не увидит список групп.

### 5. Включить форму на сайте

1. Ссылку для вызова из шага 3 впишите в `index.html`, в строку `var FORM_ENDPOINT = "";`. Ссылка не секретная: её можно прислать в чат, Claude впишет.
2. Отправьте с сайта тестовую заявку: в группе должно появиться сообщение «🌿 Новая заявка на фестиваль».

## Если что-то не так

- **Заявка не пришла, а сайт пишет «Не получилось отправить».** Откройте функцию → **Логи**. Строка `max_failed` содержит ответ Max:
  - `401` — неверный токен;
  - `403` или `404` — бот не в группе или неверный `MAX_CHAT_ID`.

  Сама заявка лежит в логах в строке `request`.
- **Сайт перешёл на другой адрес.** Добавьте переменную `ALLOWED_ORIGINS`: адреса через запятую, например `https://fest.mirra-spb.ru,https://новый-адрес.ru`. Заявки с других сайтов функция не принимает.
- **Защита от спама.** В форме есть скрытое поле, которое люди не видят, а боты заполняют. Кроме того, заявка, отправленная быстрее чем за 3 секунды, считается спамом. В обоих случаях функция отвечает «принято», но в группу ничего не шлёт и пишет в логи строку `spam`.
- **Что проверяет функция.** Заявку без имени, без телефона из 10–15 цифр или без согласия на обработку данных она не принимает.

## После правки index.py

Пересоберите архив и загрузите его в функцию заново (шаг 3.4):

```bash
python -c "import zipfile as z; f=z.ZipFile('fest-zayavki.zip','w',z.ZIP_DEFLATED); [f.write(n) for n in ('index.py','russian_trusted_ca.pem')]; f.close()"
```

Команду запускать из папки `backend/`. Промежуточный сертификат Минцифры действует до 06.03.2027, корневой — до 2032 года. Если API Max перестанет принимать соединение, функция сама переключится на запасной адрес `platform-api.max.ru`.
