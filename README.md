## Фото ведущих для анфилады
Фото вырезаются из фона и ставятся в арку, поэтому нужны снятые одинаково: от груди или от пояса, вся голова с запасом сверху, руки ниже плеч и не обрезаны краем кадра, однотонный фон, контрастный к волосам, дневной свет. Не селфи. Исходник присылать файлом, без сжатия мессенджером. Оригиналы — в «06_Спикеры/», вырезанные — в `proto/img/` (WebP с прозрачностью, высота до 1000 px, голова ≈ 40% высоты кадра).

## Хостинг
Сайт живёт на **https://fest.mirra-spb.ru** — GitHub Pages, публичный репозиторий [RomanVanish/mirra-fest](https://github.com/RomanVanish/mirra-fest), ветка `main`, корень папки (так же устроен zal.mirra-spb.ru — репозиторий `mirra-zal`). Эта папка и есть репозиторий.
- DNS: запись `CNAME fest → romanvanish.github.io.`; файл `CNAME` в папке не удалять — в нём домен для GitHub Pages.
- HTTPS: сертификат Let's Encrypt выпускает и продлевает GitHub сам.
- Выложить правку: пересобрать `index.html` (`python3 build.py`), затем `git add -A`, `git commit -m "…"`, `git push`. Сайт обновляется за 1–2 минуты.

## Интерактивные элементы
Каждый добавлен отдельным коммитом — любой можно откатить (`git log`, затем `git revert <коммит>`).
- **Живая восьмёрка** («Идея»): ползунок «страх ↔ любовь» сжимает и раскрывает петли; «Подышать 30 секунд» — 3 цикла вдох 4 с / выдох 6 с.
- **Карта дня** (раздел после «Идеи»): колода, карта переворачивается — страх → опора и практика на сегодня, можно поделиться. Тексты — в массиве `CARDS` в скрипте, **черновик, на согласовании со Светланой**.
- **Схема маршрута** («Ваш маршрут»): условная схема холла и трёх залов, путь выбранной группы рисуется по шагам. Положение залов — объект `MAP` в скрипте.
- **«Отпустите то, что тяжело нести»** (финал): плотная связка шариков с подписями (тревога, страх ошибиться, обида, вина…) на нитках к одному узелку; нажатие — шарик улетает и тает. Подписи — массив `LET` в скрипте.
- **Рассвет по прокрутке**: солнце идёт по линии под шапкой, фон страницы теплеет от розоватого к персиковому.
