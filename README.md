## Файлы
| Файл | Что это |
|---|---|
| `page.html` | **Исходник сайта** — правим только его. Из него же публикуется превью-ссылка для команды |
| `index.html` | Готовая страница для хостинга. Собирается из `page.html` командой `python3 build.py`, вручную не правим |
| `build.py` | Сборка `index.html` из `page.html` |
| `.source/` | Прежние версии сайта (первый, тёмный вариант) — не актуальны, не удаляем |
| `img/` | Фото ведущих, обрезаны 4:5, 640×800 (пока Кочурова и Трофимова, исходники — в «06_Спикеры/») |

| `ИЛЛЮСТРАЦИИ.md` | Список мест под иллюстрации (12 штук), форматы и промпты для ChatGPT |
| `proto/arches.html` | Прототип блока «Ведущие»: анфилада арок в тёмном колючем лесу, передняя арка по центру, остальные уходят по дуге к свету. При проходе сквозь арку сгущается и рассеивается тёмная дымка, с каждым шагом сцена светлее — «из тьмы к свету». На сайт пока не перенесён. Фото — вырезанные из фона портреты в `proto/img/` (Трофимова, Виноградова; у остальных силуэты) |

## Фото ведущих для анфилады
Фото вырезаются из фона и ставятся в арку, поэтому нужны снятые одинаково: от груди или от пояса, вся голова с запасом сверху, руки ниже плеч и не обрезаны краем кадра, однотонный фон, контрастный к волосам, дневной свет. Не селфи. Исходник присылать файлом, без сжатия мессенджером. Оригиналы — в «06_Спикеры/», вырезанные — в `proto/img/` (WebP с прозрачностью, высота до 1000 px, голова ≈ 40% высоты кадра).

## Откуда тексты
- Описания МК, подписи ведущих, «Что важно знать» — из **«03_Брошюра для гостей.md»** (единственный источник текстов для гостей). При правке брошюры — перенести изменения сюда.

## Хостинг
Сайт живёт на **https://fest.mirra-spb.ru** — GitHub Pages, публичный репозиторий [RomanVanish/mirra-fest](https://github.com/RomanVanish/mirra-fest), ветка `main`, корень папки (так же устроен zal.mirra-spb.ru — репозиторий `mirra-zal`). Эта папка и есть репозиторий.
- DNS: запись `CNAME fest → romanvanish.github.io.`; файл `CNAME` в папке не удалять — в нём домен для GitHub Pages.
- HTTPS: сертификат Let's Encrypt выпускает и продлевает GitHub сам.
- Выложить правку: пересобрать `index.html` (`python3 build.py`), затем `git add -A`, `git commit -m "…"`, `git push`. Сайт обновляется за 1–2 минуты.

## Заявки и оплата
Сейчас форма ничего не отправляет: в `page.html` переменная `FORM_ENDPOINT` пустая, гость видит пометку «черновик». Варианты:
1. **Заявка без оплаты** — нужен приёмник: свой маленький обработчик, который пересылает заявку в Telegram, или сервис форм.
